# Instituto Conexões do Sertão

Projeto acadêmico de desenvolvimento front-end.

Plataforma institucional de uma ONG fictícia localizada em Cajazeiras, Paraíba, desenvolvida para promover iniciativas sociais, culturais e ambientais e incentivar a participação da comunidade.

## Tecnologias utilizadas

- HTML5: estrutura semântica das páginas.
- CSS3: estilização e responsividade.
- JavaScript: interatividade e navegação dinâmica.

## Funcionalidades

- Apresentação institucional da ONG.
- Divulgação dos projetos sociais.
- Formulário de cadastro de participantes.
- Navegação dinâmica em uma Single Page Application (SPA).

## Objetivo acadêmico

Aplicar conhecimentos de desenvolvimento front-end, controle de versões, acessibilidade, otimização e publicação web.

## Controle de versões

O projeto utiliza Git e GitHub, seguindo uma estratégia baseada em GitFlow.

- main: versão estável e publicada.
- develop: integração das alterações em desenvolvimento.
- feature/: desenvolvimento de funcionalidades específicas.

As alterações são registradas por meio de commits semânticos e integradas utilizando pull requests.

## Acessibilidade

O projeto tem como referência as diretrizes WCAG 2.1, nível AA.

Estão previstos testes de navegação por teclado, contraste de cores, estrutura semântica, formulários e compatibilidade com leitores de tela.

A conformidade será avaliada e documentada após a realização dos testes.
