  Plataforma institucional de uma ONG fictícia localizada em Cajazeiras, Paraíba, desenvolvida para promover iniciativas sociais, culturais e ambientais e incentivar a participação da comunidade.

  Tecnologias utilizadas
  HTML5, CSS3 e JavaScript.
  Funcionalidades
- Apresentação institucional da ONG.
- Divulgação dos projetos sociais.
- Formulário de cadastro de participantes.
- Navegação dinâmica em uma Single Page Application (SPA).
  Objetivo acadêmico
  Aplicar conhecimentos de desenvolvimento front-end, controle de versões, acessibilidade, otimização e publicação web.
